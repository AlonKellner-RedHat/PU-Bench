# Phase 4 Analysis - Stratified by Label Frequency (Multi-Seed)

**Goal:** Separate results by label frequency (c) to understand how method_prior
performance depends on the amount of labeled data available.

**Configuration:**
- **Datasets**: 7 (20News, Connect4, FashionMNIST, IMDB, MNIST, Mushrooms, Spambase)
- **Methods**: 2 VPU variants (vpu_mean_prior, vpu_nomixup_mean_prior)
- **Label frequencies (c)**: 3 values [0.01, 0.5, 0.99] - analyzed separately
- **True priors (π)**: 7 values [0.01, 0.1, 0.3, 0.5, 0.7, 0.9, 0.99]
- **Seeds**: 10 ['seed_100', 'seed_1024', 'seed_200', 'seed_2048', 'seed_300', 'seed_400', 'seed_42', 'seed_456', 'seed_500', 'seed_789']

**Key insight:** The 'auto' prior is c × π, so:
- At c=0.01: auto ranges from 0.0001 to 0.0099 (very low)

- At c=0.99: auto ranges from 0.0099 to 0.9801 (very high)
